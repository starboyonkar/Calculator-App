# Scientific Calculator

Open `index.html` in a browser to use the calculator. The UI supports standard arithmetic and a variety of scientific functions:

- sin, cos, tan, asin, acos, atan
- sqrt, ln (natural log), log (base 10), log10
- pi (π), e
- exponent with `^`

Keyboard shortcuts:

- `Enter` = evaluate
- `Backspace` = delete
- `Esc` = clear

Files:

- [index.html](index.html) — main UI
- [styles.css](styles.css) — styling
- [script.js](script.js) — logic and evaluation
